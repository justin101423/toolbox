이미지 → PDF란?

이미지 → PDF 변환 도구는 여러 장의 JPG, PNG, WebP 사진을 하나의 PDF 파일로 묶어줍니다. 스캔한 문서나 사진을 PDF로 제출해야 할 때 편리하게 활용하세요. 추가한 순서가 PDF 페이지 순서가 되며, 모든 처리는 브라우저 안에서만 이루어집니다.

각 이미지가 독립적인 PDF 페이지로 변환되며, 원본 이미지 크기를 그대로 반영합니다. 파일 목록에서 × 버튼으로 불필요한 이미지를 제거할 수 있습니다.
