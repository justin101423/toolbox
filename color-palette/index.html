조화로운 5색 팔레트를 만듭니다. 색을 클릭하면 HEX 코드가 복사돼요.

컬러 팔레트 생성이란?

컬러 팔레트 생성 도구는 색상 이론을 바탕으로 조화로운 5가지 색상을 자동으로 만들어 줍니다. 웹사이트·앱·브랜드 디자인의 색상 시스템을 구성하거나, 인테리어·일러스트 색상 조합을 탐색할 때 활용하세요. 버튼 클릭이나 스페이스바로 새 팔레트를 계속 생성할 수 있습니다.

마음에 드는 색상 칸을 클릭하면 HEX 코드가 클립보드에 자동 복사됩니다. CSS나 디자인 툴에 바로 붙여넣어 사용하세요.
