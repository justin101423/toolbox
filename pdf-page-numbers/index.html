PDF 페이지 번호 넣기

PDF의 모든 페이지에 쪽 번호를 자동으로 넣습니다. 위치·시작 번호·형식·크기를 고를 수 있고, 파일은 브라우저 안에서만 처리됩니다.

번호를 넣을 PDF 선택
끌어다 놓거나 클릭
사용법
  1. 쪽 번호를 넣을 PDF를 선택합니다.
  2. 위치(상·하, 좌·중·우)와 번호 형식, 글자 크기를 정합니다.
  3. 표지를 건너뛰려면 시작 번호를 조절합니다.
  4. 번호 넣고 저장을 누르면 쪽 번호가 들어간 새 PDF를 내려받습니다.
활용 팁
  • 제출용 문서: 보고서·계약서·과제 PDF에 쪽 번호가 있으면 인쇄·검토 시 순서를 확인하기 좋습니다.
  • 전체 쪽수 표시: '1 / N' 형식을 쓰면 몇 쪽 중 몇 쪽인지 한눈에 보여 누락 확인에 유용합니다.
  • 여백 조절: 본문과 겹치면 여백 값을 키워 번호를 가장자리로 더 밀어내세요.
자주 묻는 질문
Q. 일부 페이지부터 번호를 매길 수 있나요?

시작 번호를 바꿀 수 있습니다. 예를 들어 표지를 1쪽으로 세지 않으려면 시작 번호를 0이나 원하는 값으로 조정하면 됩니다. 다만 현재 도구는 모든 페이지에 번호를 넣으므로, 표지에 번호를 빼고 싶다면 표지를 제외한 PDF로 만든 뒤 번호를 넣는 방식을 권합니다.

Q. 번호 형식은 어떤 것을 고를 수 있나요?

숫자만(1, 2, 3), 전체 쪽수 포함(1 / 10), 가운데 점선 형식(- 1 -) 중에서 고를 수 있습니다. 위치는 위쪽·아래쪽과 왼쪽·가운데·오른쪽을 조합해 정할 수 있고, 글자 크기도 조절할 수 있어 문서 양식에 맞게 넣을 수 있습니다.

Q. PDF 파일이 서버로 전송되나요?

아니요. 쪽 번호를 넣고 새 PDF로 저장하는 모든 처리가 사용자의 브라우저 안에서 이뤄집니다. 파일은 서버로 전송되거나 저장되지 않으므로 계약서·보고서처럼 민감한 PDF도 안전하게 처리할 수 있습니다.
