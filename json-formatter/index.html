JSON 포매터

엉킨 JSON을 보기 좋게 정렬하거나, 한 줄로 압축하고, 문법 오류를 잡아줍니다.

사용법
  1. 왼쪽 텍스트 창에 JSON을 붙여넣습니다. API 응답, 설정 파일, 로그 등 어떤 JSON이든 가능합니다.
  2. "정렬" 버튼을 누르면 2칸 들여쓰기로 가독성 좋게 포맷됩니다.
  3. "압축" 버튼을 누르면 공백과 줄바꿈이 모두 제거된 한 줄 JSON이 만들어집니다.
  4. 문법 오류가 있으면 정확한 오류 위치를 알려줍니다. 오류를 수정한 뒤 다시 시도하세요.
  5. "복사" 버튼으로 결과를 클립보드에 저장해 바로 사용합니다.
활용 팁
  • API 디버깅: API 응답으로 받은 한 줄짜리 JSON을 "정렬"하면 키-값 구조를 한눈에 파악할 수 있어 디버깅 시간이 크게 줄어듭니다. Postman 없이 빠르게 확인할 때 유용합니다.
  • 전송 효율화: 서버 요청 바디나 파일 저장 시 "압축"을 사용해 불필요한 공백을 없애세요. 대용량 JSON에서 수십 KB 이상의 트래픽을 줄일 수 있습니다.
  • 흔한 JSON 오류: 마지막 원소 뒤 쉼표(trailing comma), 키가 쌍따옴표가 아닌 경우, 작은따옴표 사용이 가장 자주 발생하는 문법 오류입니다. 오류 메시지에 줄 번호가 표시되므로 해당 위치를 먼저 확인하세요.
자주 묻는 질문
Q. 대용량 JSON 파일도 처리할 수 있나요?

브라우저에서 처리하므로 수십 MB 이상의 JSON은 느릴 수 있습니다. 일반적인 API 응답(수십 KB~수 MB)은 즉시 처리됩니다.

Q. 한글이 포함된 JSON도 정상 처리되나요?

네. JavaScript의 JSON.parse/stringify는 유니코드를 완벽히 처리하므로 한글, 이모지 등이 포함된 JSON도 문제없습니다.

Q. 결과를 파일로 다운로드할 수 있나요?

현재 다운로드 기능은 없습니다. 복사 버튼으로 클립보드에 저장한 뒤 텍스트 에디터에 붙여넣어 저장하세요.
