JSON 포매터

엉킨 JSON을 보기 좋게 정렬하거나, 한 줄로 압축하고, 문법 오류를 잡아줍니다.

JSON 포매터란?

JSON 포매터는 압축된 JSON을 들여쓰기로 정렬해 가독성을 높이거나, 반대로 한 줄로 압축해 전송 효율을 높이는 도구입니다. 문법 오류가 있으면 정확한 오류 위치를 안내하므로 API 개발과 디버깅에 유용합니다. 모든 처리는 브라우저 안에서만 이루어집니다.

정렬 버튼은 2칸 들여쓰기로 변환하고, 압축 버튼은 공백·줄바꿈을 모두 제거합니다. 결과는 복사 버튼으로 바로 클립보드에 저장할 수 있습니다.
