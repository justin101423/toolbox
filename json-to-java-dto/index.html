JSON → Java DTO

JSON을 붙여넣으면 Java DTO 클래스를 자동 생성합니다.

JSON 입력
Java DTO 출력
JSON → Java DTO 변환기 안내

JSON 객체의 키를 분석해 적절한 Java 타입으로 매핑합니다. 중첩 객체는 static inner class로, 배열은 List<T>로 변환됩니다. Lombok @Data 옵션을 켜면 getter/setter/toString 없이 어노테이션 하나로 대체합니다.

camelCase 필드명은 JSON 키를 그대로 사용합니다. snake_case 키는 자동으로 camelCase로 변환됩니다. 생성된 코드는 참고용이므로 실제 프로젝트에 맞게 검토 후 사용하세요.
