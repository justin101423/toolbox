PDF 페이지 분할

큰 PDF에서 원하는 페이지만 뽑아 새 PDF로 저장합니다.

✂
PDF 파일을 끌어다 놓거나 클릭한 개 선택
사용법
  1. 분할할 PDF를 드래그 앤 드롭하거나 클릭해 업로드합니다.
  2. 업로드 후 표시되는 전체 페이지 수를 확인합니다.
  3. 추출할 페이지 범위를 입력합니다. 예: "1-3, 5, 8-10" → 1·2·3·5·8·9·10페이지 추출.
  4. "분할 후 다운로드" 버튼을 누르면 지정한 페이지만 담긴 새 PDF가 다운로드됩니다.
활용 팁
  • 필요한 페이지만 공유: 긴 보고서에서 요약본(1~5페이지)만 따로 공유하거나, 계약서에서 서명 페이지만 추출하는 등 문서의 일부만 전달할 때 편리합니다.
  • 범위 입력 형식: 연속 범위는 "5-10", 단일 페이지는 "7", 복합 지정은 "1, 3, 5-8, 12"처럼 조합합니다. 순서가 바뀌어 입력해도 내부적으로 오름차순 정렬됩니다.
  • 포트폴리오·챕터 추출: 이력서에 첨부한 포트폴리오에서 특정 프로젝트 페이지만 추출하거나, 책 스캔 PDF에서 원하는 챕터만 잘라내는 용도로 활용하세요.
자주 묻는 질문
Q. 분할 후 원본 파일이 변경되나요?

아닙니다. 브라우저 메모리에서 읽어 새 PDF를 만들므로 원본 파일은 그대로 유지됩니다.

Q. 페이지를 중복 입력하면 어떻게 되나요?

중복 입력된 페이지는 한 번만 추출됩니다. "1-3, 2, 3"을 입력해도 1·2·3페이지가 각각 한 번씩만 포함됩니다.

Q. 홀수·짝수 페이지만 추출할 수 있나요?

현재 범위 및 개별 지정 방식만 지원합니다. 홀수/짝수 필터 기능은 없으므로 직접 번호를 나열해 입력하세요.
