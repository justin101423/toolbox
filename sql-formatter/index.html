SQL 포매터

한 줄로 길게 늘어진 SQL을 보기 좋게 정렬·들여쓰기해 드립니다. 데이터베이스 방언과 키워드 대소문자를 골라 보세요. 모든 처리는 브라우저 안에서 이뤄집니다.

SQL 입력
정렬 결과
사용법
  1. 정렬할 SQL 쿼리를 입력합니다.
  2. 사용하는 데이터베이스 방언과 키워드 대소문자, 들여쓰기를 고릅니다.
  3. 정렬하기를 누르면 보기 좋게 정렬된 결과가 나타납니다. 복사로 가져갑니다.
SQL 포매팅이 하는 일

SQL 포매터는 쿼리의 모양만 정리합니다. 키워드를 줄 맞춰 배치하고 들여쓰기를 넣어, 길고 복잡한 쿼리를 읽기 쉽게 만들어 줍니다. 실행 결과는 전혀 바뀌지 않습니다.

  • 줄바꿈·들여쓰기: SELECT·FROM·WHERE·JOIN을 줄 단위로 나눠 구조를 드러냅니다.
  • 키워드 대소문자: 예약어를 대문자로 통일해 테이블·컬럼명과 구분합니다.
  • 방언(dialect): MySQL·PostgreSQL 등 DB별 식별자 표기에 맞춰 정렬합니다.

정리된 쿼리는 리뷰·공유·디버깅이 훨씬 쉬워집니다. 들여쓰기·대문자 규칙은 SQL 쿼리 정리 가이드를 참고하세요.

활용 팁
  • 리뷰·공유 전에: 길게 한 줄로 작성된 쿼리를 정렬하면 JOIN·WHERE 조건이 한눈에 들어와 코드 리뷰나 공유가 쉬워집니다.
  • 키워드 대문자 관례: SELECT·FROM·WHERE 같은 키워드를 대문자로 통일하면 식별자(테이블·컬럼명)와 구분되어 가독성이 올라갑니다. 팀 컨벤션에 맞춰 선택하세요.
  • 방언을 맞추면 정확: 백틱(MySQL), 대괄호(SQL Server) 같은 식별자 표기는 방언을 맞춰야 어긋나지 않습니다. 결과가 어색하면 방언을 바꿔 보세요.
자주 묻는 질문
Q. 방언(dialect)은 왜 고르나요?

데이터베이스마다 고유한 키워드와 문법이 조금씩 다릅니다. MySQL, PostgreSQL, SQL Server, Oracle 등 사용하는 데이터베이스에 맞는 방언을 고르면 백틱·대괄호 같은 식별자 표기나 특수 함수가 더 정확하게 정렬됩니다. 잘 모르겠으면 '표준 SQL'을 사용하세요.

Q. 쿼리의 동작이 바뀌지는 않나요?

아니요. 포매터는 줄바꿈·들여쓰기·키워드 대소문자 같은 '모양'만 정리할 뿐, 쿼리의 의미나 실행 결과는 바꾸지 않습니다. 다만 문법 오류가 있는 쿼리는 정렬이 어색하게 나올 수 있으니, 정렬 결과가 이상하면 원본 문법을 먼저 확인하세요.

Q. 입력한 SQL이 서버로 전송되나요?

아니요. SQL 정렬은 모두 사용자의 브라우저 안에서 이뤄지며, 입력한 쿼리는 서버로 전송되거나 저장되지 않습니다. 테이블·컬럼명이 드러나는 업무용 쿼리도 안심하고 정리할 수 있습니다.

Q. 여러 개의 쿼리를 한 번에 정렬할 수 있나요?

네. 세미콜론(;)으로 구분된 여러 쿼리를 함께 넣으면 각 쿼리가 순서대로 정렬됩니다. 다만 방언이 섞여 있으면 일부 식별자 표기가 어긋날 수 있으니, 같은 DB의 쿼리끼리 정리하는 것이 정확합니다.

Q. 한 줄로 압축(minify)도 되나요?

이 도구는 보기 좋게 펼치는 정렬에 집중합니다. 쿼리를 한 줄로 합쳐야 한다면 정렬 결과의 줄바꿈을 공백·줄바꿈 정리 도구로 없애면 됩니다. 다만 SQL은 보통 가독성을 위해 정렬된 형태로 보관·공유하는 편이 좋습니다.
