마크다운 문법 입문 — 제목·목록·링크·표 한 번에 정리

가이드 · 개발약 6분2026.06.09

깃허브 README, 노션 메모, 블로그 글… 요즘 글쓰기 도구는 대부분 마크다운(Markdown)을 지원합니다. 마우스로 버튼을 누르는 대신 # 제목, **굵게**처럼 간단한 기호로 서식을 입히는 방식이죠. 한 번 익히면 어디서나 빠르게 정돈된 글을 쓸 수 있습니다. 핵심 문법만 모았습니다.

이 글의 순서
  1. 제목·강조·줄바꿈
  2. 목록
  3. 링크·이미지·코드·인용
  4. 표

제목·강조·줄바꿈

# 제목 1 ## 제목 2 ### 제목 3 **굵게** *기울임* ~~취소선~~ 문단을 나누려면 빈 줄을 하나 둡니다.
  • 제목: # 개수로 단계(1~6). # 뒤에 공백을 꼭 넣습니다.
  • 강조: **굵게**, *기울임*, ~~취소선~~.
마크다운 → HTML 변환작성하면 실시간 미리보기 · HTML 복사 미리보기 →

목록

- 순서 없는 목록 - 두 번째 항목 - 들여쓰기로 하위 항목 1. 순서 있는 목록 2. 두 번째 3. 세 번째

순서 없는 목록은 -(또는 *), 순서 있는 목록은 1.로 시작합니다. 공백 두 칸으로 들여쓰면 하위 항목이 됩니다.

링크·이미지·코드·인용

[보이는 글자](https://example.com) ![대체텍스트](이미지주소.png) `인라인 코드` > 인용문은 꺾쇠로 시작합니다.
  • 링크: [글자](주소) — 이미지는 앞에 !를 붙입니다.
  • 코드: 백틱(`) 하나로 인라인, 세 개로 여러 줄 코드 블록.
  • 인용: 줄 앞에 >.

표

| 이름 | 나이 | |------|------| | 홍길동 | 30 | | 김철수 | 25 |

파이프(|)로 칸을 나누고, 두 번째 줄의 ---로 머리글과 본문을 구분합니다. :---(왼쪽), :--:(가운데)로 정렬도 지정할 수 있습니다.

팁: 문법이 헷갈리면 마크다운 미리보기 도구에 직접 입력해 보세요. 왼쪽에 쓰면 오른쪽에 변환 결과가 바로 보여, 빠르게 익힐 수 있습니다. 표·목록을 손으로 만들기 번거로우면 표 변환기도 함께 활용하세요.
자주 묻는 질문
Q. 마크다운은 어디에 쓰나요?

깃허브·깃랩의 README와 이슈, 노션·옵시디언 같은 메모 앱, 디스코드·슬랙 메시지, 많은 블로그 에디터가 마크다운을 지원합니다. 한 번 익혀 두면 여러 플랫폼에서 같은 문법으로 서식 있는 글을 빠르게 쓸 수 있습니다.

Q. 마크다운으로 줄바꿈은 어떻게 하나요?

문단을 나누려면 빈 줄을 하나 넣습니다. 같은 문단 안에서 줄만 바꾸려면 줄 끝에 공백 두 칸을 넣거나, 플랫폼에 따라 그냥 엔터로도 줄바꿈이 되는 경우가 있습니다. 동작이 플랫폼마다 조금 다르므로 미리보기로 확인하는 것이 좋습니다.

Q. 마크다운을 HTML로 바꿀 수 있나요?

네. 마크다운은 본래 HTML로 변환되어 표시됩니다. 마크다운 미리보기 도구에 작성하면 실시간으로 변환 결과를 보고, 생성된 HTML 코드를 복사해 블로그나 웹페이지에 붙여 넣을 수 있습니다.
