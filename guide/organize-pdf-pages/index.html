PDF 페이지 삭제·순서 바꾸기 — 스캔 문서 정리법

가이드약 4분2026.06.11

스캔을 마치고 보니 백지가 한 장 끼어 있고, 5쪽이 3쪽 앞에 가 있고, 한 장은 거꾸로 들어갔습니다. 다시 스캔할 필요는 없습니다. PDF는 페이지 단위로 들어내고, 옮기고, 돌릴 수 있으니까요. 정리 작업의 종류와 순서를 정리합니다.

이 글의 순서
  1. 이럴 때 필요합니다
  2. 정리의 3가지 작업 — 삭제·순서·회전
  3. 범위 추출이 필요하면 — 분할
  4. 정리 4단계

이럴 때 필요합니다

  • 스캔 중 끼어든 백지·중복 페이지 빼기
  • 합치고 보니 뒤섞인 페이지 순서 바로잡기
  • 거꾸로·옆으로 들어간 페이지 바로 세우기
  • 제출 전 불필요한 페이지(메모, 표지 등) 정리

정리의 3가지 작업 — 삭제·순서·회전

  • 삭제 — 페이지 썸네일에서 뺄 페이지를 표시하면 남은 페이지로 새 PDF가 만들어집니다.
  • 순서 변경 — 썸네일을 원하는 위치로 옮기면 그 차례대로 저장됩니다.
  • 회전 — 누운·뒤집힌 페이지만 골라 90°·180° 회전. 페이지별로 따로 적용됩니다.
안심 포인트: 어떤 작업을 해도 원본 파일은 그대로입니다. 정리 결과는 새 PDF로 저장되므로 실수하면 원본에서 다시 시작하면 됩니다.

범위 추출이 필요하면 — 분할

"고치기"가 아니라 "나누기"가 목적이라면 분할 도구가 맞습니다.

  • 100쪽 보고서에서 10~20쪽만 따로 한 파일로 → PDF 페이지 분할
  • "1-3, 7, 9-12"처럼 범위·개별 페이지를 지정해 추출할 수 있습니다.
  • 기억법: 한 파일을 고친다 → 정리 / 여러 파일로 나눈다 → 분할.

정리 4단계

  1. PDF를 페이지 정리 도구에 올립니다 — 페이지 썸네일이 나열됩니다.
  2. 뺄 페이지는 삭제 표시, 누운 페이지는 회전, 순서는 드래그로 조정합니다.
  3. 새 PDF로 저장합니다.
  4. 저장본을 열어 페이지 수·순서·방향을 확인합니다. 용량이 크면 PDF 압축으로 마무리하세요.

자주 묻는 질문
Q. PDF에서 한 페이지만 지우고 싶은데 다시 만들어야 하나요?

다시 만들 필요 없습니다. PDF 페이지 정리 도구에 파일을 올리면 페이지 썸네일이 나열되고, 지울 페이지에 삭제 표시만 하면 남은 페이지로 새 PDF가 만들어집니다. 원본 파일은 그대로 보존되므로, 실수해도 원본에서 다시 시작하면 됩니다.

Q. 페이지 정리와 분할은 뭐가 다른가요?

정리는 한 문서를 다듬는 작업(삭제·순서 변경·회전)이고, 분할은 문서에서 원하는 범위를 뽑아 별도 파일로 만드는 작업입니다. 100쪽 보고서에서 잘못 스캔된 3쪽을 빼고 순서를 고치는 건 정리 도구, 그중 10~20쪽만 따로 한 파일로 보내는 건 분할 도구를 쓰면 됩니다. 헷갈리면 '한 파일을 고친다 → 정리, 여러 파일로 나눈다 → 분할'로 기억하세요.

Q. 스캔하다 거꾸로 들어간 페이지도 고칠 수 있나요?

네. 페이지 정리 도구에서 해당 페이지의 썸네일만 90도·180도 회전하면, 저장되는 PDF에 그 방향이 그대로 반영됩니다. 양면 스캔에서 뒷면이 모두 거꾸로 들어간 경우에도 해당 페이지들만 골라 180도 돌리면 한 번에 해결됩니다. 회전은 페이지별로 따로 적용할 수 있습니다.
