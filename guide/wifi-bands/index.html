와이파이 2.4GHz vs 5GHz — 빠른데 벽에 약한 이유

가이드약 4분2026.06.12

와이파이 목록에 "우리집"과 "우리집_5G"가 나란히 뜹니다. 공유기가 두 대인 게 아니라 한 공유기가 두 주파수로 동시에 방송하는 것입니다. 어느 쪽에 붙느냐로 속도가 몇 배 달라질 수 있으니, 두 대역의 성격을 알아 둘 가치가 충분합니다.

  3. 상황별 선택 가이드
  4. 알아 두면 좋은 것들

요약: 2.4는 멀리 가는 느린 길, 5는 가까운 빠른 길입니다. (6GHz를 더 쓰는 Wi-Fi 6E/7 공유기도 원리는 같습니다 — 높은 주파수일수록 빠르고 짧게.)

왜 빠른 쪽이 벽에 약한가

  • 주파수가 높을수록 한 번에 실어 나를 수 있는 정보가 많아 빠릅니다.
  • 대신 파장이 짧아져 벽·가구를 만나면 더 많이 흡수·반사됩니다 — 저음(낮은 주파수)은 벽 너머로 들리지만 고음은 잘 안 들리는 것과 같은 이치입니다.
  • 2.4GHz는 전자레인지·블루투스와 같은 대역을 공유해서, 성능과 별개로 간섭에 시달립니다 — 전자레인지를 돌리면 와이파이가 끊기는 집이 실제로 있습니다.

상황별 선택 가이드

  1. 공유기와 같은 방·거실 — 5GHz. 속도 차이가 가장 크게 납니다.
  2. 벽 두세 개 너머 방·다른 층 — 5GHz가 약하게 잡히면 2.4GHz가 오히려 안정적일 수 있습니다.
  3. 영상통화·게임·대용량 다운로드 — 가능하면 5GHz, 더 좋은 건 유선. 속도가 안 나오는 것 같으면 Mbps와 MB/s 차이부터 확인해 보세요.
  4. 스마트 전구·플러그 설정 — 기기 대부분이 2.4GHz 전용이므로, 설정하는 동안 폰도 2.4GHz에 연결.

알아 두면 좋은 것들

  • 이름이 하나뿐이라면 — 공유기가 두 대역을 한 이름으로 합쳐(밴드 스티어링) 알아서 배정 중입니다. 편리하지만 IoT 설정 때는 헷갈림의 원인이 되기도 합니다.
  • 공유기 위치가 절반 — 집 중앙, 바닥보다 높게, 금속·수조 옆 피하기. 위치 이동이 장비 교체보다 효과가 클 때가 많습니다.
  • 손님에게 와이파이 알려줄 때 — 비밀번호를 불러주는 대신 QR코드를 만들어 두면 카메라로 스캔해 바로 접속됩니다. 방법은 와이파이 QR 공유 가이드에서.

자주 묻는 질문
Q. 우리 집 와이파이가 두 개 잡히는데 뭐가 다른가요?

같은 공유기가 두 주파수 대역으로 동시에 전파를 쏘고 있는 것입니다. 보통 이름 끝에 5G(또는 5GHz)가 붙은 쪽이 5GHz 대역, 아무 표시가 없거나 2.4G가 붙은 쪽이 2.4GHz 대역입니다. 2.4GHz는 멀리 가고 벽을 잘 통과하지만 속도가 느리고 혼잡하며, 5GHz는 빠르지만 거리·장애물에 약합니다. 공유기와 가까운 곳에서는 5G 쪽, 먼 방이나 벽 너머에서는 2.4G 쪽이 일반적으로 잘 맞습니다.

Q. 기가 인터넷인데 와이파이만 느린 건 왜인가요?

2.4GHz 대역에 연결되어 있을 가능성이 큽니다. 2.4GHz는 규격상 실효 속도가 수십 Mbps 수준에 머무는 경우가 많아, 회선이 기가급이어도 와이파이 구간에서 막힙니다. 5GHz로 바꿔 연결하고 공유기 가까이에서 다시 측정해 보세요. 그래도 느리면 공유기가 구형(기가 미지원)이거나 채널 혼잡일 수 있습니다. 전자레인지·블루투스가 2.4GHz와 같은 대역을 써서 간섭을 일으키는 것도 흔한 원인입니다.

Q. 스마트 전구·플러그가 와이파이에 연결이 안 돼요.

대부분의 보급형 IoT 기기는 2.4GHz만 지원합니다. 비용과 도달 거리 때문입니다. 그런데 설정하는 스마트폰이 5GHz에 연결되어 있으면 기기를 찾지 못하는 경우가 많습니다. 해결법은 설정하는 동안만 스마트폰을 2.4GHz 와이파이에 연결하는 것입니다. 두 대역이 같은 이름으로 합쳐져 있다면 공유기 설정에서 잠시 이름을 분리하거나, 기기를 공유기 가까이에서 설정하면 성공률이 올라갑니다.
