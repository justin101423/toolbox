프린터 없이 PDF로 저장 — Ctrl+P의 숨은 기능

도구상자 지기가이드약 4분2026.06.12

예약 확인 페이지를 증빙으로 남겨야 하는데 프린터가 없습니다. 캡처? 길면 잘립니다. 정답은 인쇄 기능입니다 — Ctrl+P에서 프린터 대신 "PDF로 저장"을 고르면, 종이 대신 파일로 인쇄됩니다.

PC — Ctrl+P → PDF로 저장

  1. 저장하고 싶은 페이지에서 Ctrl + P(맥 Cmd + P)를 누릅니다.
  2. 프린터(대상) 목록에서 "PDF로 저장"을 선택합니다 — 모든 주요 브라우저에 내장돼 있습니다.
  3. 미리보기로 페이지 수·잘림을 확인하고 저장을 누릅니다.
  4. 웹페이지뿐 아니라 인쇄가 되는 모든 프로그램(메일, 문서, 사진 뷰어)에서 같은 방법이 통합니다.
이럴 때 쓰세요: 예약·결제 확인서 증빙, 나중에 바뀔 수 있는 공지·약관 보관, 기사 스크랩, 워드 없는 PC에서 문서를 PDF로 제출해야 할 때. 화면 캡처와 달리 텍스트가 살아 있어 검색·복사가 됩니다.

스마트폰에서

  • 아이폰 — 사파리 공유 → "프린트" → 프린터 대신 다시 공유 아이콘 → PDF로 저장. 또는 스크린샷 → "전체 페이지" 탭으로 긴 화면을 통째로 PDF로.
  • 안드로이드 — 크롬 메뉴 → 공유(또는 인쇄) → "PDF로 저장".
  • 종이 서류는 카메라로 찍어 이미지→PDF 도구로 묶으면 스캐너 없이 해결 — 요령은 사진을 PDF로 제출하기에서.

잘리지 않게 — 옵션 손보기

  • 내용이 잘릴 때 — 배율을 "맞춤"이나 90% 안팎으로. 넓은 표는 용지 방향을 가로로.
  • 배경색·이미지가 사라질 때 — 추가 설정의 "배경 그래픽" 켜기.
  • 날짜·URL이 인쇄될 때 — "머리글 및 바닥글" 끄기.
  • 광고·메뉴까지 저장될 때 — 브라우저 읽기 모드(리더 보기)에서 인쇄하면 본문만 깔끔하게 담깁니다.

저장한 PDF 정리하기

  • 여러 페이지를 따로 저장했다면 하나로 합쳐 보관하세요 — 영수증 묶음·자료집 만들기에 좋습니다.
  • 페이지 순서·회전이 어긋났다면 정리 도구로, 용량이 크면 압축으로 — 모두 브라우저 안에서 처리됩니다.
  • 자주 쓰는 조합: 월말에 영수증 PDF 모아 합치기 → 파일명에 날짜 → 클라우드 보관.

자주 묻는 질문
Q. 웹페이지를 PDF 파일로 저장하려면 어떻게 하나요?

인쇄 기능을 이용하면 됩니다. PC 브라우저에서 Ctrl+P(맥은 Cmd+P)를 누르고 프린터(대상) 목록에서 'PDF로 저장'을 선택한 뒤 저장 버튼을 누르면 그 페이지가 PDF 파일이 됩니다. 프린터가 없어도 되고 별도 프로그램도 필요 없습니다. 예약 확인서, 결제 내역, 공지사항처럼 나중에 바뀌거나 사라질 수 있는 화면을 증빙으로 남길 때 가장 확실한 방법입니다.

Q. 저장한 PDF가 잘리거나 이상하게 나와요.

인쇄 대화상자의 옵션 몇 가지를 손보면 대부분 해결됩니다. 내용이 잘리면 배율을 '맞춤' 또는 90% 안팎으로 낮추고, 표가 페이지에 안 들어가면 용지 방향을 가로로 바꿔 보세요. 배경색·이미지가 사라졌다면 추가 설정에서 '배경 그래픽' 항목을 켜면 됩니다. 머리글·바닥글(날짜·URL)이 거슬리면 같은 곳에서 끌 수 있습니다. 그래도 깨지는 사이트는 본문만 드래그해 복사한 뒤 문서 프로그램에 붙여 PDF로 내보내는 우회가 있습니다.

Q. 스마트폰에서도 PDF로 저장할 수 있나요?

됩니다. 아이폰 사파리는 공유 버튼에서 '프린트'를 선택한 뒤 프린터 대신 공유 아이콘을 다시 눌러 PDF로 저장하거나, 스크린샷 후 '전체 페이지' 탭으로 긴 화면을 통째로 PDF로 만들 수 있습니다. 안드로이드 크롬은 메뉴에서 공유 또는 인쇄를 열고 'PDF로 저장'을 고르면 됩니다. 종이 서류는 카메라로 찍어 이미지→PDF 변환 도구로 묶는 것이 스캐너 없이 PDF를 만드는 가장 쉬운 길입니다.
