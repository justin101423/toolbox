PDF 합치기·나누기·용량 줄이기 무료로 하는 법

가이드약 5분2026.06.09

제출 서류를 하나의 PDF로 합쳐 달라거나, 반대로 특정 페이지만 빼서 보내야 할 때가 있습니다. 유료 프로그램이나 수상한 변환 사이트에 회원가입까지 할 필요는 없습니다. 브라우저에서 바로, 그리고 파일을 외부로 보내지 않고 처리하는 방법을 정리합니다.

이 글의 순서
  1. 여러 PDF를 하나로 합치기
  2. 필요한 페이지만 분리·추출하기
  3. 페이지 순서·회전 정리하기
  4. PDF 용량 줄이기
  5. 왜 브라우저 처리가 안전한가

여러 PDF를 하나로 합치기

지원서·증빙서류·스캔본이 여러 파일로 흩어져 있을 때, 하나로 합치면 제출과 관리가 편합니다.

  • 합칠 PDF들을 한꺼번에 올립니다.
  • 순서를 드래그로 정렬합니다(이 순서대로 이어 붙습니다).
  • 합치기를 누르면 하나의 PDF로 내려받아집니다.

필요한 페이지만 분리·추출하기

전체 문서에서 특정 페이지만 보내야 할 때, 또는 한 PDF를 여러 개로 쪼개야 할 때 사용합니다. 페이지 번호(예: 1-3, 5)를 지정해 원하는 부분만 새 PDF로 추출할 수 있습니다.

페이지 순서·회전 정리하기

스캔하다 보면 페이지가 뒤집히거나 순서가 엉키기 쉽습니다. 이럴 땐 페이지를 회전하고, 순서를 바꾸고, 필요 없는 페이지를 삭제하는 정리 도구가 편합니다. 합치기 전에 한 번 정리해 두면 결과물이 훨씬 깔끔합니다.

PDF 용량 줄이기

메일 첨부나 제출 사이트의 용량 제한에 걸렸다면, PDF 용량을 줄여야 합니다. PDF가 무거운 이유는 대부분 안에 든 이미지, 특히 고해상도 스캔본 때문입니다.

  • 스캔 문서: 압축 효과가 큽니다. 내부 이미지의 해상도·품질을 낮추면 용량이 크게 줄어듭니다.
  • 글자 위주 문서: 이미 가벼워서 줄어드는 폭이 작습니다. 이때는 합치는 파일 수를 줄이는 편이 낫습니다.

왜 브라우저 처리가 안전한가

계약서·통장 사본·주민등록등본 같은 문서를 아무 변환 사이트에나 올리는 건 위험합니다. 파일이 그 회사 서버에 저장·보관될 수 있기 때문입니다. 도구상자의 PDF 도구는 모든 처리를 이용자의 브라우저 안에서 수행해, 파일이 인터넷으로 전송되지 않습니다. 인터넷 연결을 잠시 끊어도 동작하는 이유가 그래서입니다.

참고: 작업이 끝난 PDF는 내려받은 뒤 다운로드 폴더에만 남습니다. 공용 PC라면 사용 후 다운로드 파일을 정리하는 습관을 권합니다.
자주 묻는 질문
Q. PDF를 합치거나 나눌 때 파일이 외부 서버로 올라가나요?

도구상자의 PDF 도구는 브라우저 안에서 처리되어 파일이 서버로 업로드되지 않습니다. 계약서·증빙서류처럼 민감한 문서도 외부에 남지 않고 안전하게 다룰 수 있습니다.

Q. PDF 용량은 어떻게 줄이나요?

용량이 큰 PDF는 대부분 안에 든 이미지(특히 스캔본) 때문입니다. PDF 압축 도구로 내부 이미지의 해상도와 품질을 낮추면 용량이 크게 줄어듭니다. 글자 위주의 문서는 줄어드는 폭이 작습니다.

Q. PDF에서 특정 페이지만 빼낼 수 있나요?

네. PDF 분할 도구에서 원하는 페이지 번호나 범위를 지정하면 해당 페이지만 새 PDF로 추출할 수 있습니다. 필요 없는 페이지를 삭제하거나 순서를 바꾸는 것도 가능합니다.
