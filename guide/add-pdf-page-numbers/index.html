PDF에 페이지 번호 넣는 법 — 위치·시작번호·표지 제외까지

도구상자 지기가이드약 4분2026.06.15

보고서·논문·계약서를 PDF로 제출할 때 페이지 번호가 없으면 어딘가 어설퍼 보입니다. 다행히 번호 넣기는 어렵지 않습니다 — 다만 표지 제외와 시작 번호만 제대로 잡으면 됩니다.

번호가 필요한 이유

  • 참조 — "12쪽을 보세요"처럼 위치를 가리킬 수 있습니다.
  • 분실 확인 — 인쇄·제본 시 빠진 장을 바로 알아챕니다.
  • 완성도 — 제출 문서의 기본 격식입니다.

위치와 형식

옵션추천
위치하단 중앙(가장 무난) / 우측 하단
형식"12" 또는 "12 / 40"(총쪽 표시)
글자 크기본문보다 작게 9~11pt
여백본문·이미지와 안 겹치게 여백 안쪽
제본 문서: 양면 인쇄해 묶을 거라면 바깥쪽(홀수 쪽 오른쪽·짝수 쪽 왼쪽)에 두면 펼쳤을 때 번호가 잘 보입니다. 화면용 PDF는 하단 중앙이 깔끔합니다.

표지 빼고 본문부터

  1. 표시 범위를 본문 시작 페이지부터로 지정 → 표지·목차에는 번호가 안 찍힙니다.
  2. 시작 번호를 1로 지정 → 본문 첫 장이 1쪽이 됩니다.
  3. 논문 격식이 필요하면 목차까지는 i·ii(로마자), 본문부터 1로 나누기도 합니다.

넣는 순서

  1. PDF를 올리고 번호 위치·형식·시작번호를 정합니다.
  2. 표지를 뺄 거면 시작 페이지를 지정합니다.
  3. 미리보기로 겹침이 없는지 확인하고 저장합니다.
  4. 원본은 따로 보관 — 번호는 새겨지면 지우기 어렵습니다.

번호를 넣기 전에 페이지 순서·삭제·회전을 정리하려면 PDF 페이지 정리법을 먼저 보세요.

자주 묻는 질문
Q. 표지에는 번호를 안 넣고 본문부터 1쪽으로 매길 수 있나요?

네, 두 가지를 따로 설정하면 됩니다. 먼저 번호를 표시할 페이지 범위를 본문 시작 페이지부터로 정하면 표지·목차에는 번호가 찍히지 않습니다. 그리고 시작 번호를 1로 지정하면 본문 첫 장이 1쪽이 됩니다. 보고서는 보통 표지를 빼고 본문부터, 논문은 목차까지는 i·ii(로마자), 본문부터 1로 매기는 식인데, 간단한 문서라면 표지 제외 + 본문 1쪽부터로 충분합니다.

Q. 번호 위치는 어디가 좋나요?

가장 무난한 건 아래쪽 가운데(하단 중앙)와 오른쪽 아래입니다. 양면 인쇄해 제본하는 문서라면 바깥쪽(홀수 쪽은 오른쪽, 짝수 쪽은 왼쪽)에 두기도 하지만, 화면으로만 볼 PDF는 하단 중앙이 가장 깔끔합니다. 본문 글자나 이미지와 겹치지 않도록 여백 안쪽에 자리를 잡고, 글자 크기는 본문보다 약간 작게(9~11pt 정도) 하는 것이 보기 좋습니다.

Q. 한 번 넣은 번호를 다시 지울 수 있나요?

페이지 번호는 PDF 위에 글자로 새겨지므로, 저장한 뒤에는 쉽게 지우기 어렵습니다. 그래서 번호를 넣기 전 원본 파일은 따로 보관해 두는 것이 안전합니다. 위치나 시작 번호를 잘못 잡았다면 원본에서 다시 설정해 새로 저장하면 됩니다. 도구상자의 PDF 작업은 모두 브라우저 안에서 처리되어 파일이 서버로 올라가지 않으니, 여러 번 다시 시도해도 부담이 없습니다.
