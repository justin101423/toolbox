개발 표기법 변환기

단어·식별자를 camelCase·snake_case·kebab-case 등으로 한 번에 변환합니다. 값을 누르면 복사됩니다.

사용법
  1. 변환할 단어나 식별자를 입력합니다(공백·밑줄·하이픈·camelCase 모두 인식).
  2. 여러 표기법으로 변환된 결과가 즉시 표로 나타납니다.
  3. 원하는 값을 클릭하면 클립보드에 복사됩니다.
활용 팁
  • API 필드 매핑: 백엔드의 snake_case 필드를 프런트의 camelCase로 바꿀 때 빠르게 변환할 수 있습니다.
  • 상수·CSS: 상수는 CONSTANT_CASE, CSS 클래스·URL 슬러그는 kebab-case가 관례입니다.
  • 일관성: 한 프로젝트 안에서는 같은 표기법을 일관되게 쓰는 것이 가독성과 협업에 좋습니다.
자주 묻는 질문
Q. camelCase와 snake_case는 무엇이 다른가요?

둘 다 여러 단어를 하나의 식별자로 잇는 표기법입니다. camelCase는 첫 단어는 소문자로 시작하고 이어지는 단어의 첫 글자를 대문자로 붙입니다(userName). snake_case는 모두 소문자로 쓰고 단어 사이를 밑줄로 잇습니다(user_name). 언어·팀 규칙에 따라 변수·함수에 다른 표기법을 씁니다.

Q. 어떤 표기법으로 변환할 수 있나요?

camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE(대문자 스네이크), dot.case, 띄어쓰기 소문자·제목 케이스 등으로 변환합니다. 입력은 공백·밑줄·하이픈은 물론 camelCase의 대소문자 경계까지 단어로 인식하므로, 어떤 형식으로 넣어도 원하는 표기법으로 바꿀 수 있습니다.

Q. 한글이나 숫자가 섞여도 되나요?

숫자는 단어의 일부로 그대로 유지됩니다. 한글 등 영문이 아닌 문자도 깨지지 않고 보존되지만, 대소문자 개념이 없어 케이스 변환 효과는 영문에만 적용됩니다. 변수명은 보통 영문과 숫자로 짓는 것을 권장하며, 이 도구는 영문 식별자 변환에 가장 적합합니다.
