공백·줄바꿈 정리

텍스트의 불필요한 공백·줄바꿈·특수 공백 문자를 실시간으로 정리합니다. 옵션을 켜고 끄면 결과가 즉시 반영됩니다.

사용법
  1. 정리할 텍스트를 상단 입력창에 붙여넣거나 직접 입력합니다.
  2. 정리 옵션 체크박스를 켜고 끄면 결과가 실시간으로 갱신됩니다. 기본 3가지 옵션(연속 공백 합치기, 줄 앞뒤 공백 제거, 빈 줄 합치기)이 켜져 있습니다.
  3. "정리된 결과" 창에서 결과를 확인하고, 원본·정리 후 글자 수 차이를 통계로 확인합니다.
  4. "결과 복사" 버튼으로 정리된 텍스트를 클립보드에 저장합니다.
활용 팁
  • 웹·PDF에서 복사한 텍스트 정제: 웹페이지나 PDF에서 글을 복사하면 보이지 않는 Non-Breaking Space(U+00A0)와 같은 특수 공백이 함께 딸려옵니다. "특수 공백을 일반 공백으로" 옵션을 켜면 이런 숨겨진 문자를 제거해 문서 편집기나 에디터에 붙여넣을 때 레이아웃이 틀어지는 문제를 방지할 수 있습니다.
  • 엑셀·스프레드시트 데이터 처리: 엑셀 셀을 복사하면 셀 구분자로 탭(\t)이 포함됩니다. "탭을 공백으로 변환"과 "연속 공백 하나로 합치기"를 함께 적용하면 탭 구분 데이터를 단일 공백 구분 형식으로 빠르게 변환할 수 있습니다.
  • SQL·코드 한 줄로 만들기: 여러 줄로 작성한 SQL 쿼리나 API 요청 바디를 한 줄로 전달해야 할 때 "모든 줄바꿈 제거"를 사용하세요. "연속 공백 하나로 합치기"와 함께 적용하면 줄바꿈이 공백으로 치환된 뒤 중복 공백까지 정리된 깔끔한 결과가 나옵니다.
자주 묻는 질문
Q. 특수 공백이 뭔가요?

일반 스페이스바(U+0020) 외에도 줄바꿈 없는 공백(Non-Breaking Space, U+00A0), 좁은 공백(U+202F), 전각 공백(U+3000) 등 다양한 유니코드 공백 문자가 존재합니다. Word·PDF·웹 페이지에서 복사할 때 이런 문자가 섞여오면 검색이나 문자열 비교 시 의도치 않은 오류가 생길 수 있습니다.

Q. "모든 줄바꿈 제거"와 "연속 빈 줄 합치기"는 어떻게 다른가요?

"연속 빈 줄 합치기"는 두 줄 이상 연속된 빈 줄을 한 줄로 줄여 단락 구조를 유지합니다. "모든 줄바꿈 제거"는 모든 줄바꿈을 공백으로 바꿔 전체를 하나의 줄로 만듭니다. 단락을 보존하면서 정리하려면 전자를, 한 줄짜리 결과가 필요하면 후자를 선택하세요.

Q. 입력한 텍스트가 외부로 전송되나요?

아닙니다. 모든 처리는 브라우저의 JavaScript 엔진에서만 실행됩니다. 입력한 텍스트는 서버로 전송되지 않으므로 업무 문서나 민감한 내용도 안심하고 사용할 수 있습니다.
