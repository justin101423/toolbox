PDF → 이미지 변환

PDF 각 페이지를 JPG 또는 PNG 이미지로 저장합니다. 여러 페이지는 ZIP 파일로 묶어 다운로드합니다.

▧
PDF 파일을 끌어다 놓거나 클릭페이지 범위 선택 가능
PDF를 선택하면 페이지 수가 표시됩니다.
PDF 이미지 변환 안내

PDF → 이미지 변환 도구는 문서의 각 페이지를 브라우저에서 렌더링해 JPG 또는 PNG 파일로 저장합니다. 발표자료 일부를 이미지로 공유하거나, PDF 첫 페이지를 썸네일로 만들 때 유용합니다.

여러 페이지를 변환하면 ZIP으로 묶어 다운로드합니다. 모든 처리는 사용자의 브라우저에서 완료되며 PDF 파일은 서버로 전송되지 않습니다.
