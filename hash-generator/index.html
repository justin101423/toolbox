해시 함수란?

해시 함수는 임의의 데이터를 고정 길이의 문자열로 변환하는 단방향 함수입니다. MD5와 SHA-1은 빠르지만 보안 취약점이 알려져 있어 파일 무결성 확인 정도에만 사용하고, 보안이 중요한 경우 SHA-256 이상을 사용하세요.

입력이 조금만 달라져도 전혀 다른 해시가 생성되는 것이 특징입니다. 모든 처리는 브라우저 내에서만 이루어집니다.
