# Search Console 색인 요청 대기열

> 구글 Search Console > URL 검사 > 색인 생성 요청. 하루 한도 약 10개 — 위에서부터 순서대로, 요청한 URL은 체크. **색인 대상(scripts/indexed.json) 125개 URL만 담았습니다** — noindex 처리한 페이지는 요청하지 않습니다.
>
> **순서(2026-10-03 재정렬)**: Day 1~3 앞쪽 26개는 구글이 6월에 읽고 "크롤링됨 – 현재 색인이 생성되지 않음"으로 둔 페이지입니다(이후 본문을 보강했으므로 다시 읽게 하는 것이 최우선). 그 뒤는 구글이 아직 읽지 않은 페이지입니다(핵심 → 도구 → 가이드).
