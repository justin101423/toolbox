SVG → PNG 변환

벡터 SVG 파일이나 코드를 원하는 크기의 PNG 이미지로 바꿉니다. 배율·배경(투명/흰색)을 고르고 다운로드하세요. 모든 처리는 브라우저 안에서 이뤄집니다.

SVG 파일을 끌어다 놓거나 클릭해서 선택
.svg 파일 하나 · 서버로 전송되지 않습니다
— 또는 —
너비 px
여기에 변환 결과가 표시됩니다
사용법
  1. SVG 파일을 끌어다 놓거나 클릭해 선택합니다. 또는 아래 칸에 SVG 코드를 붙여넣어도 됩니다.
  2. 원하는 크기를 정합니다 — 간단히 배율(×1·×2·×4)을 고르거나, 너비(px)를 직접 입력하면 비율을 유지해 변환합니다.
  3. 배경을 투명 또는 흰색 중에서 고른 뒤 미리보기로 결과를 확인합니다.
  4. PNG 다운로드를 눌러 이미지를 저장합니다.
활용 팁
  • 고해상도가 필요하면 배율을 올리세요: 인쇄·발표 자료용은 ×2~×4로 변환하면 또렷한 PNG가 됩니다. SVG는 벡터라 키워도 변환 시점엔 깨지지 않습니다.
  • 로고·아이콘은 투명 배경: 다른 화면이나 색 배경 위에 얹을 이미지는 투명 배경으로 만들면 자연스럽게 어울립니다.
  • 코드 붙여넣기로 빠르게: 디자인 툴에서 SVG 코드를 복사했다면 파일로 저장하지 않고 바로 붙여넣어 변환할 수 있습니다.
자주 묻는 질문
Q. SVG가 안 열리거나 변환되지 않아요.

올바른 SVG 파일(.svg)이거나 <svg ...>로 시작하는 코드여야 합니다. 외부 폰트·이미지를 link로 불러오는 SVG는 보안상 캔버스에 그릴 수 없어 변환이 안 될 수 있습니다. 이때는 폰트를 도형(path)으로 변환하거나 외부 참조 없는 SVG를 사용하세요. 또 width·height나 viewBox가 모두 없으면 크기를 알 수 없어 기본 512px로 그립니다.

Q. 크기를 키워도 화질이 안 깨지나요?

SVG는 벡터라 변환 시점에 정한 크기에 맞춰 선명하게 PNG로 그려집니다. 배율을 ×2·×4로 올리거나 너비(px)를 크게 지정하면 그만큼 고해상도 PNG가 만들어집니다. 다만 PNG로 변환한 뒤에는 일반 비트맵 이미지가 되므로, 이미 만든 PNG를 다시 키우면 깨집니다. 필요한 최종 크기를 정해 한 번에 변환하세요.

Q. 배경을 투명하게 하려면요?

배경 옵션에서 '투명'을 고르면 SVG에 채워진 부분만 남고 나머지는 투명한 PNG가 만들어집니다. 로고·아이콘처럼 다른 배경 위에 얹을 이미지에 적합합니다. 인쇄나 흰 바탕이 필요하면 '흰색'을 고르세요. PNG는 투명도를 지원하므로 투명 배경이 그대로 저장됩니다.
