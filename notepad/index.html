임시 메모장

작성 내용이 브라우저에 자동 저장됩니다. 새로고침해도 사라지지 않아요.

사용법
  1. 텍스트 창에 메모할 내용을 바로 입력합니다. 저장 버튼 없이 입력 즉시 자동으로 저장됩니다.
  2. 탭을 닫거나 새로고침해도 내용이 유지됩니다. 같은 브라우저에서 다시 열면 이어서 작성할 수 있습니다.
  3. "복사" 버튼으로 전체 내용을 클립보드에 한 번에 저장합니다.
  4. "초기화" 버튼으로 내용을 전부 지우고 새 메모를 시작합니다.
활용 팁
  • 개발 작업용 임시 공간: 쿼리문, API 키, 스크립트 조각처럼 잠깐 보관하고 쓸 텍스트를 저장해두기 좋습니다. 다른 탭을 열었다가 돌아와도 내용이 그대로 남아 있습니다.
  • 즐겨찾기 활용: 이 페이지를 브라우저 즐겨찾기에 등록해두면 급하게 메모할 때 앱 실행 없이 바로 열 수 있습니다. 퇴근 후 다음 날 다시 열어도 내용이 유지됩니다.
  • 공용 PC 사용 금지: localStorage는 해당 기기·브라우저에 저장되므로 공용 컴퓨터에서는 민감한 정보 입력을 삼가세요. 비밀번호나 개인 식별 정보는 이 메모장에 저장하지 않는 것이 좋습니다.
자주 묻는 질문
Q. 저장 내용이 갑자기 사라졌는데 왜 그런가요?

브라우저 캐시·쿠키 삭제, 시크릿 모드 종료, 또는 LocalStorage 초기화 시 내용이 함께 삭제됩니다. 장기 보관이 필요하면 외부에 별도 저장하세요.

Q. 다른 기기에서도 메모를 볼 수 있나요?

아닙니다. 내용은 현재 기기의 브라우저 LocalStorage에만 저장됩니다. 기기 간 동기화는 지원하지 않습니다.

Q. 시크릿(인코그니토) 모드에서도 메모가 보관되나요?

시크릿 모드는 창을 닫으면 저장 공간을 비우므로 메모도 함께 사라집니다. 메모를 계속 남기려면 일반 창에서 사용하고, 중요한 내용은 따로 복사해 두세요.
