PDF 합치기

여러 개의 PDF 파일을 순서대로 하나로 합칩니다. 위아래 순서가 그대로 적용돼요.

📄
PDF 파일들을 끌어다 놓거나 클릭여러 개 선택 가능
사용법
  1. 합칠 PDF 파일들을 드래그 앤 드롭하거나 클릭해 업로드합니다. 2개 이상이어야 병합 버튼이 활성화됩니다.
  2. 파일 목록에서 순서를 확인합니다. 이 순서가 최종 PDF의 페이지 순서가 됩니다.
  3. 순서를 변경하려면 ×로 파일을 제거하고 올바른 순서로 다시 추가하세요.
  4. "병합 후 다운로드" 버튼을 클릭하면 하나로 합쳐진 PDF가 다운로드됩니다.
활용 팁
  • 파일명 번호 정렬 활용: 파일명 앞에 번호를 붙여(01_본문.pdf, 02_첨부.pdf) 정렬한 뒤 업로드하면 원하는 순서대로 병합하기 쉽습니다.
  • 업무 서류 통합: 계약서, 견적서, 첨부 서류처럼 여러 문서를 이메일에 하나씩 첨부하는 번거로움을 없애고 하나의 PDF로 깔끔하게 전달하세요.
  • 페이지 방향 유지: 각 PDF의 세로·가로 방향이 달라도 원본 방향 그대로 유지됩니다. 단, 원본의 북마크(목차)와 하이퍼링크는 병합 후 유지되지 않을 수 있습니다.
자주 묻는 질문
Q. 병합 후 원본 파일의 북마크(목차)가 유지되나요?

브라우저 기반 pdf-lib는 기본 북마크를 유지하지 않습니다. 목차가 중요한 경우에는 전문 PDF 편집 도구를 사용하세요.

Q. 암호화된 PDF도 합칠 수 있나요?

비밀번호가 걸린 PDF는 브라우저에서 읽을 수 없어 처리되지 않습니다. 병합 전에 암호를 먼저 해제하세요.

Q. 합친 PDF를 다시 분할할 수 있나요?

이 도구는 합치기 전용입니다. 분할이 필요하다면 PDF 페이지 분할 도구를 이용하세요.
